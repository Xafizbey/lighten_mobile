# Lighten для iPhone

Копия папки `apps/ios` из монорепозитория `Xafizbey/luckylife`.

Нативное приложение ученика на SwiftUI. Работает с тем же API, что и кабинет
ученика `apps/web`, и повторяет его экраны: вход, главная, неделя, урок с
материалом и заданиями, результат и спор об оценке, эссе, экзамен, прогресс,
профиль, плюс анимация запуска («свет включается»). Кабинета преподавателя в приложении нет.

**Статус: каркас, ещё ни разу не собирался.** Код написан в облачном Linux без
Xcode. Первая сборка на Маке почти наверняка покажет несколько ошибок
компиляции: их нужно поправить.

## Как открыть

Нужны Mac с Xcode 16 или новее и [XcodeGen](https://github.com/yonaskolb/XcodeGen).
Проект Xcode в git не хранится, он собирается из `project.yml`:

```bash
brew install xcodegen
```

```bash
xcodegen
open Lighten.xcodeproj
```

В Xcode: таргет **Lighten** → Signing & Capabilities → выбрать свою команду
(Team). Bundle ID уже `app.lighten.ios`, такой же, как в App Store Connect.

Код сервера и сайта живёт в монорепозитории `Xafizbey/luckylife`, в этом
репозитории только приложение. Оно зависит только от API на сервере.

## Адрес сервера

Приложение ходит в `<адрес кабинета ученика>/api/...`, так же как сайт. Сейчас
и отладочная, и боевая сборка смотрят на рабочий сервер:
`https://app.158-180-17-16.sslip.io`. Ничего запускать у себя не нужно, войти
можно логином ученика, которого завёл преподаватель.

Адрес задаётся в `Lighten/Config/Debug.xcconfig` (запуск из Xcode) и
`Lighten/Config/Release.xcconfig` (TestFlight, App Store). Когда появится домен,
поменять адрес в обоих файлах.

Чтобы работать с сервером на своём Маке (`pnpm dev` в корне монорепозитория `luckylife`), в
`Debug.xcconfig` поставить `http:/$()/localhost:3001` для симулятора или адрес
Мака в той же сети Wi-Fi для iPhone.

## Как устроено

| Папка           | Что там                                                                            |
| --------------- | ---------------------------------------------------------------------------------- |
| `App/`          | точка входа, сессия, вкладки                                                       |
| `Networking/`   | `APIClient`: cookie-сессия, заголовок `x-llife-app: student`, ошибки               |
| `Models/`       | DTO, копия `packages/shared/src/platform.ts` и `tasks/types.ts`                    |
| `Content/`      | все строки интерфейса (копия `apps/web/content/dictionary/ru.ts`), склонения, даты |
| `Design/`       | цвета из `packages/ui/src/tokens.css`, кнопки, карточки, логотип                   |
| `Features/`     | экраны                                                                             |
| `LightenTests/` | тесты: склонения, даты, разбор JSON, формат ответов                                |

Правила те же, что у сайта (CLAUDE.md):

- **Вход**: тот же логин и пароль. Сессия — cookie API. Она хранится в
  `HTTPCookieStorage` и переживает перезапуск приложения.
- **Ключ ответа** в приложение не приходит. Проверку делает сервер, приложение
  показывает разбор: ответ ученика и верный ответ рядом.
- **Экзамен**: таймер серверный. Приложение считает до `expiresAt` с поправкой
  на разницу часов телефона и сервера. Ответы сохраняются сразу на телефон и на
  сервер. При обрыве связи экзамен открывается на том же месте.
- **Эссе**: черновик пишется на телефон при каждом изменении, на сервер — раз в
  12 секунд и при сворачивании приложения.
- **Видео** открывается ссылкой на YouTube, **аудио** играет потоком по ссылке.
- **Шрифты**: интерфейс — системный скруглённый, английский материал —
  системный с засечками. Обе гарнитуры с кириллицей, основной текст 17 pt и
  крупнее (Dynamic Type работает).

Когда меняется API или словарь сайта, нужно поправить `Models/` и
`Content/Strings.swift` вручную: общего кода с TypeScript нет.

## Что ещё не сделано

  экранам на симуляторе и на iPhone.
- Иконка временная: вариант A из `docs/brand`. Выбор логотипа за владельцем.
- Нет тёмной иконки и экрана запуска с логотипом, только цвет.

  кого ещё нет логина.
- Сервер пока на sslip.io: когда будет домен, поменять адрес в `Config/*.xcconfig`.
- Для App Store понадобятся политика конфиденциальности (ссылка), скриншоты,
  описание и демо-аккаунт ученика для проверяющих Apple.
